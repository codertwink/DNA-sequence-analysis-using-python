# DNA Sequence Analysis Using Python

## About the Project
This project demonstrates basic DNA sequence analysis using Python. It uses a real DNA sequence retrieved from the NCBI database and performs simple bioinformatics operations to understand its characteristics.

The project is developed using Python in Visual Studio Code (VS Code).

## Objectives
- Retrieve a real DNA sequence from NCBI.
- Calculate the GC content of the DNA sequence.
- Generate the reverse sequence and reverse complement.
- Save the processed sequence into a text file.
- Search the DNA sequence using NCBI BLAST to identify similar sequences.

## Tools and Technologies
- **Programming Language:** Python
- **Code Editor:** Visual Studio Code
- **Sequence Database:** NCBI Nucleotide
- **Sequence Search Tool:** NCBI BLAST (Nucleotide BLAST)

## Operations Performed

### 1. DNA Sequence Retrieval
A real DNA sequence is obtained from the NCBI Nucleotide database in FASTA format.

### 2. GC Content Calculation
GC content represents the percentage of guanine (G) and cytosine (C) bases in a DNA sequence.

**Formula:**

GC Content (%) = [(G + C) / Total Number of Bases] × 100

### 3. Reverse Complement
The reverse complement is generated by reversing the DNA sequence and replacing each nucleotide with its complementary base.

Base pairing rules:
- A → T
- T → A
- G → C
- C → G

### 4. File Handling
The reverse complement sequence is saved in a text file in multiple lines for easier reading and analysis.

### 5. BLAST Search
The original DNA sequence is submitted to NCBI Nucleotide BLAST (blastn) to identify similar sequences in biological databases.

BLAST results are studied using:
- Percentage Identity
- Query Coverage
- E-value
- Sequence Accession Number

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the Python file.
4. Enter your DNA sequence obtained from NCBI.
5. Run the Python program.

For BLAST analysis:

1. Visit https://blast.ncbi.nlm.nih.gov/Blast.cgi
2. Select Nucleotide BLAST.
3. Paste your original DNA sequence.
4. Select the nucleotide database.
5. Click BLAST and analyse the results.
